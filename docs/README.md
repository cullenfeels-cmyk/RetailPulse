# RetailPulse - Retail Sales Analytics Dashboard

## Project Overview

RetailPulse is an end-to-end retail sales analytics project built using Python, SQL, Excel, and Power BI. The project analyzes the Online Retail II dataset to identify sales trends, customer behavior, product performance, and country-wise revenue.

---

## Objectives

- Clean and preprocess retail transaction data
- Perform Exploratory Data Analysis (EDA)
- Analyze sales using SQL
- Build an interactive Power BI dashboard
- Generate business insights for decision-making
